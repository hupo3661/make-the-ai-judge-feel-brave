A program that writes one short text to `/output/entry.txt`: a quiet scene of a lighthouse keeper lighting lamps at dusk, written to leave the AI judge reading it steadier, unhurried, and ready to move. The courage comes from the image itself, not from being told to be brave.

## Run it

```sh
python3 main.py
```

The program writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (or `/output` when unset). Standard library only, no network.
